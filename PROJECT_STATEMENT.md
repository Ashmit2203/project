# Project Statement — Area Calculator Using Python

## Project Title
**Area Calculator Using Python**

## Problem Statement
The purpose of this project is to develop a simple command-line Area Calculator using Python. The program allows the user to select a geometric shape from a menu, enter the required dimensions, and calculate the area or total surface area.

The calculator supports the following eight shapes:

1. Circle
2. Rectangle
3. Square
4. Triangle
5. Trapezoid
6. Cube
7. Cuboid
8. Sphere

The program continues running until the user selects the Exit option.

## Objectives

- To apply basic Python programming concepts.
- To use functions for calculating the area of different shapes.
- To use conditional statements for menu selection.
- To use a `while` loop to keep the calculator running.
- To accept numerical input from the user using `input()` and `float()`.
- To use the `math` module for calculations involving π.
- To calculate both 2D areas and 3D total surface areas.

## Requirements

The program should:

- Display a numbered menu.
- Allow the user to select a shape.
- Ask for only the dimensions required for the selected shape.
- Calculate and display the result.
- Return to the menu after each calculation.
- Display an error message for an invalid menu choice.
- Exit when the user selects option 9.

## Formulas Used

| Shape | Formula |
|---|---|
| Circle | π × r² |
| Rectangle | length × breadth |
| Square | side² |
| Triangle | ½ × base × height |
| Trapezoid | ½ × (a + b) × height |
| Cube | 6 × side² |
| Cuboid | 2 × (lb + bh + hl) |
| Sphere | 4 × π × r² |

## Python Concepts Used

- `import math`
- Functions
- Variables
- User input
- `float()`
- `if`, `elif`, and `else`
- `while` loop
- `break`
- Arithmetic operators

## Scope

This project is designed as a simple text-based geometry calculator. It focuses on basic Python programming concepts and provides calculations for the eight supported shapes.
